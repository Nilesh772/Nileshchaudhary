# Full Stack Web Development - Complete Practical Lab Manual & Solutions (Practicals 1 to 12)

This repository contains complete, production-ready, clean, single-file implementations for all **12 Full Stack Web Development Practicals** matching the academic curriculum (React.js, Node.js, Express.js REST APIs, MongoDB Atlas, Multer, MERN Stack, RBAC Auth, and Socket.IO), along with the consolidated **Word Document** (`All_Practicals_Documentation.docx`) and **Printable PDF** (`All_Practicals_Documentation.pdf`).

## 🚀 How to Run the Practicals

### 1. React Frontend Practicals (1 to 5)
Written as modular, modern self-contained `.jsx` components:
```jsx
import Practical1 from './Practical-1';
import Practical2 from './Practical-2';
import Practical3 from './Practical-3';
import Practical4 from './Practical-4';
import Practical5 from './Practical-5'; // Axios & Fetch API
```

### 2. Backend & Full-Stack Servers (6 to 12)
```bash
npm run start:p6   # Practical 6: Express Routing & Middleware (Port 5000)
npm run start:p7   # Practical 7: Student REST API & Postman (Port 5001)
npm run start:p8   # Practical 8: Employee API + MongoDB Atlas (Port 5002)
npm run start:p9   # Practical 9: Multer File Upload & Metadata (Port 5003)
npm run start:p10  # Practical 10: Complete MERN Application (Port 5004)
npm run start:p11  # Practical 11: RBAC Blog System (Port 5005)
npm run start:p12  # Practical 12: Socket.IO Real-Time Chat (Port 5006)
```
